# felixyoung.github.io

一个简约现代的个人博客网站，采用Pitchfork风格设计，支持中文显示。

## 📁 项目结构

```
your-username.github.io/
├── index.html          # 主页
├── movies.html         # 电影评分页面
├── music.html          # 音乐评分页面
├── blog1.html          # 博客文章1
├── blog2.html          # 博客文章2
├── styles.css          # 全局样式表
└── README.md           # 使用说明
```

**评分对照表：**
- 10分 = 5个满星
- 9.5分 = 4个满星 + 1个75%星
- 9分 = 4个满星 + 1个50%星
- 8.5分 = 4个满星 + 1个25%星
- 8分 = 4个满星
